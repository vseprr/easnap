# Easnap v1.0.0

The first public release of Easnap: a native Windows app for screenshots,
annotations and short screen recordings. It runs from the system tray and keeps
capture, editing and export on your computer.

![Easnap screenshot editor with its floating annotation toolbar](https://raw.githubusercontent.com/vseprr/easnap/v1.0.0/docs/images/editor.png)

## Included

- **Screenshots:** select a monitor or custom region, adjust the frame, and copy
  the full-resolution image or save PNG/JPEG.
- **Annotations:** pen, lines, arrows, shapes, text, tags, Blur, Pixelate,
  Spotlight and Watermark, with editable objects and undo/redo.
- **Recording:** MP4 or GIF, optional cursor capture, and pause/resume without
  including paused time in the result.
- **Audio:** system audio, microphone, both or neither for MP4. GIF is silent.
- **Trim and export:** preview the recording, set In/Out points, then save or
  copy the exported file to the clipboard.
- **Desktop controls:** Ctrl+Shift+A, tray actions, saved recording preferences,
  and Light/Dark appearance.

Extract the full ZIP, open `bin`, run `Easnap.exe`, then press **Ctrl+Shift+A**.
Keep `EasnapPreviewHost.exe` beside the application. No installer or account is
required. The build targets Windows 10 and Windows 11, x64, and is unsigned;
Windows may display a publisher or reputation warning.

To check the download, compare this output with the `.zip.sha256` file:

```powershell
Get-FileHash .\Easnap-v1.0.0-windows-x64.zip -Algorithm SHA256
```

The ZIP also contains `SHA256SUMS.txt` with checksums for its packaged files.

Exit Easnap before replacing an existing copy, and replace both executables
together. Settings remain in the per-user local application-data directory.

## Validation

The Windows x64 Release build and package checks completed. The full automated
suite was not completed for this release: 29 of 37 tests finished successfully
before the run was stopped. The final capture-protected build was rebuilt
without a further test run. This release does not claim a completed physical
compatibility matrix.

## Known issues and limits

- **Trim resizing:** transient redraw artifacts can occur while resizing or
  maximizing the Trim window.
- **Compatibility coverage:** the recorded physical display baseline is 125%
  scaling. Additional Windows/GPU/audio-device, accessibility and mixed-DPI
  environments have not completed the release matrix.
- **GIF preview:** the preview plays the source recording. GIF palette and
  frame-rate conversion happen during export. Low size can omit very small
  visual changes.
- **MP4 trimming:** cut points follow video/audio sample granularity. Late
  excerpts from long recordings can take longer because decoding starts at the
  source beginning.

Build and test results, including unsuccessful runs, are recorded in
[project status](https://github.com/vseprr/easnap/blob/v1.0.0/docs/project-status.md).

## Next

**Scrollshot** is planned for v1.1: capture a scrolling region and stitch it into
one image. **OCR** is planned after v1 for extracting text from screenshots;
no release date is set. Neither feature is included in this release.
Compatibility, accessibility and the remaining Trim resize issue are also on
the work list.
