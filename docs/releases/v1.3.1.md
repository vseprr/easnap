# Easnap v1.3.1

A maintenance release: no new features. It fixes a flash around the frame
when a screenshot is fixed, a pointer that flickered while you typed text,
and the watermark field, all reported after v1.3.0.

## Fixed

- **No flash when a screenshot is fixed.** Touching the tools island, or any
  tool, takes the screenshot; for a moment the darkened screen around the
  frame brightened. The darkening is now kept steady while the picture is
  read. The picture itself was never affected.
- **A steady pointer while you type.** With Windows' "Hide pointer while
  typing" turned on, the mouse pointer dimmed and changed slightly at every
  key in the Text, Tag and watermark inputs, wherever it was. It now hides
  while you type, as it does in other applications, and comes back as soon
  as you move the mouse or leave the text. Nothing changes when the setting
  is off.
- **The watermark field.**
  - Typed wider than the field, the caret no longer stays on one letter.
  - After Esc, the clear button and the size and opacity sliders still
    change the watermark. Before, the clear button added a second, empty
    watermark and the sliders changed only the tool's defaults until another
    tool was chosen and the watermark tool chosen again.
  - Esc in the field takes back what you typed since you entered it, every
    time, also after the clear button. Before, only the first Esc did.
  - While the watermark tool is chosen, its settings always apply to the
    image's watermark; there is nothing to click on the image first.

## Upgrading from v1.3.0

- v1.3.1 installs over v1.3.0 as the same program and keeps its settings.
  Exit Easnap before you install.
- Nothing in the settings file or the registry entries changes.

```powershell

gh attestation verify .\Easnap-v1.3.1-windows-x64-setup.exe --repo vseprr/easnap
```

## Validation

- **By the owner,** on the development PC with two displays at 125 % and
  "Hide pointer while typing" on: each problem was reported there, its
  cause found with diagnostic builds that switched one suspect off at a
  time, and each correction checked by eye in a build of the fix: the
  screenshot with every tool and the island, the watermark field (long text
  with and without Caps Lock, Esc, the clear button, the sliders, another
  tool and back), and typing in Text, Tag and the watermark with the pointer
  inside and outside the frame, ended by Esc, a click and Copy.
- **In the test lab,** a virtual machine with Windows 10 22H2, no GPU and a
  125 % display: the Full set passed 66 of 66 without a retry on the sources
  of this version. New checks cover the shading while a screenshot is read,
  the watermark field and the pointer; those of the shading and of the
  watermark field fail against v1.3.0. The pointer check ran with real
  keyboard input in the lab, where the setting is on.
- Not checked: the flash itself and the stuck caret by automation (the
  darkening is kept out of every capture, and the test desktop does not
  reproduce the caret), Windows 11, an IME. The
  [validation records](validation-history.md#validation-of-v131) list the
  runs.
